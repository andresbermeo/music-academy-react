Music Academy Online

A modern, interactive web application built with React and Vite. This project showcases a landing page for a music school where users can explore different courses and enroll in them dynamically.

Features
- Dynamic Course Listing: Piano, Guitar, Singing, and Drum lessons.
- Interactive Enrollment: React state management to handle course registration.
- Responsive Design: Fully styled with CSS Grid and Flexbox for a great experience on any device.
- Live Deployment: Hosted on GitHub Pages.

Tech Stack
- Frontend: React 19
- Build Tool: Vite
- Styling: CSS3
- Deployment: gh-pages

How we worked on this
In this project, we focused on:
1. Component Structure: Organizing the app into a clean, maintainable JSX structure.
2. State Management: Using the useState hook to manage the enrollment logic.
3. Styling and UX: Creating a clean interface with hover effects and conditional button states (Enroll vs. Enrolled).
4. CI/CD: Setting up an automated deployment workflow to GitHub Pages.
